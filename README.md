# CineYellow

A movie, series and anime streaming site: Next.js 16 (App Router, Cache Components), React 19,
PostgreSQL with Drizzle ORM, Better Auth, Safepay payments and a Video.js 10 player.

Titles, posters, cast and episodes come from TMDB; anime details from AniList and AniSkip; audio
and subtitle languages from Movie of the Night; "where to watch" from TMDB (JustWatch data).
**Video plays only from sources the site has the rights to show**: your own HLS streams or the
official players of licensed hosts (Bunny, Cloudflare Stream, Mux, YouTube, Vimeo, Dailymotion),
added by an admin.

## Getting started

Requirements: Node.js 20+ and a PostgreSQL database (e.g. Neon).

```bash
npm install
cp .env.example .env          # then fill it in (see below)
npm run db:migrate            # create / update the tables
npm run dev                   # http://localhost:3000
```

Make yourself an admin (sign up first):

```bash
npm run make-admin -- you@example.com
```

Sign out and in again, then open `/admin`.

## Environment

Everything is documented in [`.env.example`](.env.example). The essentials:

| Variable | Needed for |
|---|---|
| `DATABASE_URL` | Everything (PostgreSQL) |
| `BETTER_AUTH_SECRET`, `BETTER_AUTH_URL` | Sign-in (and Trakt token encryption) |
| `TMDB_READ_TOKEN` or `TMDB_API_KEY` | The catalog; without it pages are empty |
| `SAFEPAY_PUBLIC_KEY`, `SAFEPAY_SECRET_KEY`, `SAFEPAY_WEBHOOK_SECRET` | Paid plans (without keys plans switch for free: demo mode) |
| `MOTN_API_KEY` | Audio / subtitle languages on title pages |
| `TRAKT_CLIENT_ID`, `TRAKT_CLIENT_SECRET` | Optional Trakt sync |
| `CRON_SECRET` | Background jobs (off without it) |

Never use a `NEXT_PUBLIC_` prefix for keys: everything above stays on the server.

## Admin

- **`/admin/videos`**: add the video for a movie, a whole show or one episode (several per title
  are fine: viewers fall back to the next one if one fails, or pick from the "Server" menu). Turn
  providers and sources on/off, set priorities, lock sources against automatic changes, run
  "Check now". Until a title has a video, viewers see "Not on CineYellow yet" with where it is
  legally streaming, and checkout stays paused until the first video exists.
- **`/admin/languages`**: review, edit and verify the audio / subtitle languages shown on title
  pages. Verified rows are never overwritten automatically.

## Background jobs

Route handlers under `app/api/cron/*`, scheduled in [`vercel.json`](vercel.json) (daily, which
works on every Vercel plan). Each call needs `Authorization: Bearer <CRON_SECRET>`; Vercel Cron
sends it automatically. Elsewhere, call the URLs on a schedule with that header.

| Job | Does |
|---|---|
| `source-health` | Checks video sources (HLS manifest / oEmbed), detects audio languages and quality, marks unlocked sources broken after 3 failures |
| `payments-reconcile` | Re-checks Safepay payments stuck in "pending" |
| `language-refresh` | Refreshes automatic language data older than 30 days |
| `prune` | Deletes watch history untouched for a year |

## Project layout

```
app/                 Routes (App Router)
  (auth)/            Sign-in, sign-up, landing page
  (main)/            Pages with the navbar: home, browse, title, account, admin…
  watch/             Full-screen player
  api/               Route handlers: catalog (public, rate-limited), me, payments, trakt, cron
  actions/           Server actions (each checks the session / admin role itself)
components/          React components by feature (home, title, player, watch, admin…)
  ui/, videojs/      Generated shadcn and Video.js registry components
db/                  Drizzle schema (auth-schema.ts is generated by Better Auth)
drizzle/             SQL migrations
hooks/               Client hooks
lib/
  server/            Server-only data access: auth checks (dal.ts), video sources, languages, jobs…
  tmdb/ anilist/ motn/ trakt/ payments/   One folder per outside service (server-only)
  video-providers/   Health checks per video host
  stores/            Browser state (profiles, My List, history, player prefs)
  player/            Playback helpers shared by server and client
  *.ts               Shared types and pure helpers (safe to import anywhere)
tests/               Unit tests
proxy.ts             Sign-in redirects for pages (API routes check access themselves)
```

Files that must never reach the browser start with `import "server-only"`, so importing one from
a client component fails the build.
